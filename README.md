# job-market-unemployment-analysis
Data analysis of job postings, in-demand skills, experience, education, regional hiring patterns, and unemployment rates using Python, Pandas, and Power BI.
# Job Market & Unemployment Analysis

## 📌 Project Overview

Analyzed 34K+ job postings to understand hiring patterns
across industries, education levels, experience categories,
regions, and in-demand skills.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Power BI
- SQL
- Data Visualization

## 📊 Key Analysis

- Job postings by industry
- Job postings by education
- Job postings by experience
- Top 10 in-demand skills
- Regional job distribution
- Job postings vs unemployment rate

## 🔍 Key Findings

- IT/Software was the dominant industry.
- Entry-level roles represented the largest experience category.
- Java, JavaScript and SQL were among the most frequently requested skills.
- Karnataka and Maharashtra had the highest job-posting concentration.
- Regional job-posting volume varied considerably relative to unemployment rates.
